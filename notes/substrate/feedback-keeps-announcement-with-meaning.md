# Feedback keeps announcement with meaning

The feedback batch separates page messages from field errors. Alerts are quiet by default, because content rendered with the page is already in document order; `polite` and `assertive` are reserved for messages that arrive later.

Skeletons are `aria-hidden` and the containing region owns `aria-busy`. Progress uses native semantics so `null` remains indeterminate rather than becoming a misleading zero. ErrorSurface redacts server detail when a digest is present and accepts a retry URL until a client-island callback contract is needed.
